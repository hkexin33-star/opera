# 《取帅印》

# 主要角色

秦琼：老生

程咬金：丑

秦怀玉：小生

尉迟恭：净

# 情节

唐太宗命秦琼挂帅平北后，又欲征高丽。秦琼病，拟以尉迟恭代之。程咬金力言尉迟恭粗暴，不胜任，太宗不听。程咬金乃夜往秦府嘱秦琼举子秦怀玉自代。翌日，太宗率徐勣、尉迟恭等，至秦琼处探病，兼取帅印，秦琼遂荐秦怀玉。太宗嫌其资格太浅，不敷众望，难之，谓盖苏文英勇盖世，非尉迟将军挂帅不足慑服。秦琼不得已，以印交恭，然借端呵斥，有意为难。尉迟恭志在兵符，忍气吞声，唯唯而退。勋臣轧铄，太宗亦无如何也。
