# 《祭长江》

# （一名：《祭江》）

# 主要角色

孙尚香：正旦

# 情节

赵云截江夺斗后，孙夫人独居江东。后关羽、张飞遇害，刘先主兴师大伐东吴，被陆逊用火攻之计，连营七百余里尽付一炬，先主仅以身免，赖赵云救往白帝城暂避。孙夫人在吴闻信，误谓先主已死，不胜悲痛，乃请于国太，欲往江边祭奠，以尽夫妇之谊，国太允之。夫人至江边，易白衣冠望西号哭，竟投江而死。后人相传孙夫人投江后，上帝嘉其贞洁，封为枭姬。

玉旨下，跪。

在。

听宣读。诏曰：孙尚香为夫投江，尽节一死，玉帝垂怜，封为枭姬娘娘。旨意读罢，望诏谢恩。

圣寿无疆。

众神将，保我朝见玉帝去者。
