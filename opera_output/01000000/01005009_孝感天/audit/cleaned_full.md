# 《孝感天》

# 主要角色

武姜：老旦

共叔段：小生

魏氏：正旦

# 情节

武姜自幽居城颍，终日悲啼，哀怜少子甚切。共叔段夫妻死后，以己之怙恶不悛，及母之溺爱，皆寤生阴谋故纵所致。故冤魂不散，于夜半托梦武姜，聊一相见，以慰老母舔犊之情，并恺切劝解，谓不久当与寤生有重聚之望。

# 注释

此剧即演春秋时郑庄公杀弟共叔段，并迁其母武姜于城颍之后，立誓不及黄泉母子不见之故事。

全剧俱系反二黄，演时一种幽怨愁惨之声，颇令人酸鼻不忍闻。近时善此剧者颇少。

剧名《孝感天》，殊不可解。或谓剧中共叔段鬼魂，为相沿之误，实则系演郑庄公掘地见母一节，而稍变动其情节者。故托于魂梦相见云，此说似稍近似。

寤生，郑庄公名也。

# 根据《戏考》第五册整理

# 【第一场】

（四红龙套同上，共叔段、魏氏同上。）

共叔段 （念） 丹心天地惨，黄泉路途远。

魏氏 （念） 溺爱反遭害，恩情一线牵。

共叔段、

魏氏 （同白） 我乃（共叔段）（魏氏）鬼魂是也。

共叔段 （白） 只为母后姜夫人，爱子爱媳；不想你我夫妻，反遭毒害。可叹母后在颍燕城中，思儿心切，啼哭悲声。你我夫妻，不免去至梦中，劝解一番。如此夫人请。

魏氏 （白） 夫君请。

共叔段 （白） 正是：

（念） 说破啼惨三月雨，

魏氏 （念） 梦魂惊断五更风。

（四红龙套、共叔段、魏氏同下。）

# 【第二场】

（武姜上，二宫女同上。）

武姜 （引子） 离别宫闱，空使我，老眼含泪。

（念） 生离最是苦，死别何伤乎！试看姜国母，有子不如无。

（白） 老身姜氏。只因溺爱次子共叔段，反致他夫妇身亡。可恨寤生不孝，将老身迁居颍地居住。思想起来，好不凄凉人也。

（二黄原板） 凄风苦雨多悲惨，

冷落离居泪不干。

有子如无发长叹，

老死此地几时还？

（小过门。武姜进帐子，脱帔。）

武姜 （白） 你们退下。

（二宫女同下。）

武姜 （二黄原板） 居异乡恨寂寞红日易晚，
