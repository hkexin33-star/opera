# 《独木关》

# （一名：《枪挑安殿宝》）

# 主要角色

薛礼：武生

安殿宝：净

二老军：丑

张志龙：丑

何宗宪：丑

# 情节

唐薛仁贵投效从军，隶张士贵部下，常被屈抑。虽叠斩寇将，屡建奇功，均为张士贵所冒，仍充火头军。张士贵兵次独木关，为敌将安殿宝所困，张士贵子张志龙、婿何宗宪均被擒，张士贵遣差官传令，命薛仁贵出战。薛仁贵部下周青等怒打差官，并将令箭折断，张士贵无奈，亲往薛帐拜求。时薛仁贵适抱病，但令周青等出敌，不能胜。薛仁贵在帐中闻鼓声甚急，恐不敌，因是带病上马，驰至阵前，即刺死安殿宝，众人方乘胜入关，救出张志龙、何宗宪。

# 【第一场】

（四龙套同上，张士贵上。）

张士贵 （念） 千军列队伍，万马扎团营。

（中军上。）

中军 （白） 打坏了，打坏了。

张士贵 （白） 为何这等模样？

中军 （白） 伙头军不听将令，将令箭拗断，暴打我一顿。

张士贵 （白） 想是你不会讲话，得罪他们。来，将他捆绑起来。

中军 （白） 为何将我捆绑？

张士贵 （白） 本帅自有用兵之策。

来，打道月字营。

（众人同走圆场。众伙头军同暗上。）

张士贵 （白） 前去通报：说张总爷来了。

四龙套 （同白） 张总爷来了。

众伙头军 （同白） 不晓得什么张总爷。

张士贵 （白） 吓，众位英雄对薛礼言讲，就说本帅过营探病。

周青 （白） 站下些。

有请大哥。

（二老军搀薛礼同上。）

薛礼 （二黄摇板） 在月下惊碎了英雄虎胆，

思家乡回故土千难万难。

我与那尉元帅无仇无怨，

平白地要拿我所为哪般？

（白） 周青，何事？

周青 （白） 张总爷过营探病。

薛礼 （白） 快快地有请。

周青 （白） 吓，张士贵，叫你进来。

张士贵 （白） 来了。

周青 （白） 随我进来。

张士贵 （白） 吓，薛礼，本帅来了。

薛礼 （白） 哎吓，总爷吓！小人有何德能，敢劳总爷过营探病。

张士贵 （白） 你屡次抢关夺寨，理当如此。

# 【第六场】

薛礼 （内二黄导板） 大英雄得下了冤孽病症，

（薛礼上，二老军手抬枪同上。）

薛礼 （二黄摇板） 一霎时眼昏花双目不明。

（白） 薛礼吓薛礼，想你这样英雄，得下这冤孽之病—

（二黄摇板） 似猛虎丧了命威风还在，

大将军八面威何足道哉。

抖威风上战马把贼来战，

（薛礼上马。）

薛礼 （二黄摇板） 我不杀安殿宝誓不回还。

（薛礼下。）

二老军 （同白） 薛爷去不得。

（二老军同追下。）

# 【第七场】

（安殿宝、周青同上，安殿宝打周青，周青下。）

安殿宝 （笑） 哈哈哈！

（薛礼上，扎枪，开打。安殿宝、薛礼同下。）

# 【第八场】

（周青、众伙头军同上。）

周青 （白） 众位兄弟，大哥大战安殿宝，你我在高坡一望。

众伙头军　（同白） 请。

（周青、众伙头军同上山。薛礼、安殿宝同上。薛礼挑安殿宝死。）

众伙头军 （同白） 大哥醒来！

薛礼 （二黄导板） 一霎时不觉得魂飞天外，

（二黄摇板） 众贤弟近前来细听根芽。

（白） 众位贤弟，那安殿宝呢？

众伙头军　（同白） 被大哥枪挑马下。

薛礼 （白） 此乃神灵保佑，你我望空一拜。

（〖牌子〗。）

薛礼 （白） 请总爷进关。

（四龙套同上，张士贵上，同进关，众人同下。）

# 【第九场】

（薛礼、张士贵、众伙头军同上。）

薛礼 （白） 启禀总爷：小人枪挑安殿宝，得来独木关，总爷查点。

张士贵 （白） 些须小事，何足为奇。后面埋锅造饭去吧。

（薛礼叹。）

薛礼 （白） 嗳！

（薛礼、众伙头军同下。）

张士贵 （白） 寻找二位少爷。

（张志龙、何宗宪同上。）

张志龙、

何宗宪 （同白） 我二人吃了苦了。

张士贵 （白） 不必如此，将薛礼之功，上在你二人名下就是。后帐摆宴，与你二人庆功。

（众人同下。）
