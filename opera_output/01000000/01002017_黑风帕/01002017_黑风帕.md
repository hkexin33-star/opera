# 《黑风帕》

# （一名：《牧虎关》；一名：《背鞭认子》）

# 主要角色

高旺：净

杨八妹：旦

高来：丑

张保：小生

鞑婆：旦

张兰英：老旦

# 情节

宋，杨氏父子，为潘仁美所害。有部将高旺，愤权臣骄横，忠良屈死，弃其妻子，出关逃隐。后天堂六国叛宋，使佘太君率兵征之。太君使杨八妹乔扮男装，颁取高旺回国，以资臂助。高旺情不可却，允之。行至牧虎关，守关者即高旺之妻子，高旺不知也。高旺叫关，其子张保出见，不许过关。高旺辱骂，张保出与敌，败回关上。易其媳出战，使黑风帕困高旺，而高旺之黑风帕，更高三尺。一切法术，均为高旺破。高旺见女将袅袅婷婷，忽发狂态，以游词戏弄之，媳抱惭而回。旺抵关下，见城上一白发婆娑者，直呼己名。异而询之，始知即老妻也。高旺妻开关迎旺及八妹入，数年阔别，一旦聚首，悲喜交集。即唤子媳来见，高旺见媳大惭，高旺妻笑而解之。
