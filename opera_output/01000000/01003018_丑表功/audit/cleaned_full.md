# 《丑表功》

# 主要角色

保儿：丑

万人迷：花旦

顶先生：老生

# 情节

某窑子老鸨，名万人迷。因所雇鳖腿名保儿者，做事懒惰，特地唤出吩咐。不料保儿不服，反自谓有十大汗马功劳。因此争论打架。幸得作荐保儿之教书先生到来解劝，既而万人迷与保儿算清前帐，找给大钱二百文，将保儿辞歇。

# 注释

此剧毫无情节，全是插科胡闹，俗语所谓打绷戏也。度其用意，大约隐寓老鸨乌龟，拆姘头之笑话丑态耳。此剧李百岁最称拿手，前颇轰动一时。
