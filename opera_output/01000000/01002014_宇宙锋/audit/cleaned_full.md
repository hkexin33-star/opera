# 《宇宙锋》 （一名：《金殿装疯》）

# 主要角色

赵艳容：正旦

赵高：净

秦王：小生

# 情节

秦二世胡亥，荒淫暴虐，宠任奸佞赵高，置国事于不顾。赵高有女赵艳容，美而寡。秦二世幸赵府，见之大悦，欲纳为后，赵高欣然允之。赵艳容以秦二世淫逸放纵，灭亡可待，执意不从。赵高利禄熏心，再四逼迫。有哑婢教赵艳容装疯以难之，赵艳容遂胡言乱语，指天尽地，一似真有神经病若。赵高不得已以女病疯奏二世，秦二世不信，迎赵艳容登殿。赵艳容指秦二世大骂。秦二世佯命斩首以惧之。赵艳容痛骂狂笑如故，乃放还焉。

# 【第二场】

（秦王上。）

秦王 （念） 孤王御驾到龙庭，文臣武将朝寡人。（赵高上。）

赵高 （白） 启奏万岁：小女昨晚得了疯病！秦王 （白） 昨晚灯光之下还好，即日怎么得了疯？赵高 （白） 天有不测风云，人有旦夕祸福。秦王 （白） 孤王赐她龙车凤辇带上金殿。赵高 （白） 领旨。

（赵高下。）

秦王 （白） 传御林军走上。

（四卒同上。赵艳容、赵高同上。）

赵艳容 （西皮散板） 午门外下了那龙车凤辇，行一步来至在御驾跟前。到于今顾不得抛头露面，看昏王他把我怎样旨传。赵高 （白） 儿呀，上面就是万岁。上前参见。
