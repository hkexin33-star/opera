# 《女起解》（一名：《苏三起解》）

# 主要角色

苏三：旦

张公道：丑

狱官：末

# 情节

有苏三者，自幼卖入娼寮为妓。与王公子金龙有啮臂盟。王金龙迷恋苏三，将数万巨金化尽。谁知一旦金尽床头，鸨妇即白眼相加。苏三虽恋恋不舍，然王金龙已至落魄，赖苏三私赠银两，始得进京应试。一举成名，钦放山西巡按。而苏三自王金龙去后，竟为沈洪抢至洪桐县家中为妾，后沈洪被皮氏串通王婆毒死。案发报县，诬陷苏三谋毙亲夫之罪。刑幕张允忠、洪桐县王知县，均得重金贿赂，遂不惜尽情周内，勒逼苏三画供，注成铁案，发配太原。幸王金龙至山西查阅案卷，忽见此案，不觉大惊，遂命臬司吊提全案人犯，在按院亲审。方得水落石出。

# 注释

此本乃起解出狱，发配上路，一路与解差诉说冤情之一段。后本即《三堂会审》，方与王金龙见面，最为全剧精华。此系梆子青衣中之著名好戏，昔吴彩霞唱此，娇音婉转，如百转春莺，令人不厌百回听，诚可见也。今梅兰芳方至沪上，一纸飞传，早已誉满海天，戏单方出（第二日即演《玉堂春》），而三五日后之座头，均已定满无剩，亦可见该伶于此剧之价值矣。
