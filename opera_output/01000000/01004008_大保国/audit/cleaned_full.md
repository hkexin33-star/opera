# 《大保国》 （一名：《忠心保国》）

# 主要角色

李艳妃：正旦

徐延昭：净

杨波：老生

李良：净

# 情节

相传为明穆宗隆庆驾崩，李后抱幼主万历帝临朝听政。李后父李良觊觎非分，窥窃神器，计用甘言诱李后命己摄政。李后为所惑，已坦然允之。廷臣无敢直谏者，惟兵部杨波、中山王裔孙徐延昭二人，知李良心怀不臣，其意叵测，期期以为不可，因同入宫面后，交章极谏。李后不悟，徐延昭、杨波争愈力而后愈执拗。李良因之气焰亦益盛。徐延昭愤极，遂出太祖御赐铜锤，将李良痛击，李后亦难如徐延昭罔，遂各悻悻而散。

# 注释

本剧至此收场，后徐延昭、杨波二次入宫，历陈古来外戚弄权之祸，语亦恳切，李后卒悔悟，即《二进宫》也。
