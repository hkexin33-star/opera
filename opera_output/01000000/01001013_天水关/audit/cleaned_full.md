# 《天水关》

# （一名：《初出祁山》；一名：《取三郡》）

# 主要角色

诸葛亮：老生

姜维：净

刘禅：小生

# 情节

三国，诸葛亮平南后，出师北伐，兵出祁山。魏使夏侯渊子夏侯楙御之。诸葛亮使人诈称夏侯楙受困，请各郡援救，待彼出兵后，即使赵云袭取其城。各郡守将多中计，遂得二郡。至天水，守将马遵闻信，急欲出救，为姜维所阻，谓：都督固宜救援，而天水亦不可不备，恐诸葛亮用声东击西之计以袭天水，甚可虑也。乃设计请马遵提兵出城，待蜀兵来，回击之，内应外合，以困蜀兵。马遵从之，离城不远。赵云果至，马遵与姜维夹击之，赵云大败而回。诸葛亮大惊，深赞姜维之能。探知姜维甚孝，派兵往冀城取其母。姜维闻信提兵往救，诸葛亮乃择军中貌似姜维者，乔扮姜维，夜半功城，谓姜维已降汉。马遵骇甚。黎明伪姜维即退，适真姜维回天水，请马遵开城。马遵以为诳己也，乱箭射之。姜维拟投他郡，为诸葛亮伏兵所困，不得已遂降。
